A backdoor has been found hiding in the web server that runs Control Web Panel (CWP), a free panel for managing Linux hosting servers, researchers at QiAnXin's XLab said this week. The backdoored web server executes commands that attackers send via web requests, and those requests never appear in its access logs. The researchers do not yet know how attackers get the root access the installer needs.

The backdoor is cwpsrv itself, rebuilt with extra code, the researchers found in their technical analysis. The researchers published these indicators: If a server is infected, the researchers recommend three steps: The archive uploaded from Brazil also held the Ebury malware, an OpenSSH backdoor and credential stealer active since at least 2009. The researchers do not know whether the two are related, and say different attackers may have planted them on the same server.
