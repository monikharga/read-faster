Nearly every agent security pitch now ends on the same promise: the product stops the bad action in real time. The year's largest agent launches placed agents inside platforms the buyer does not own. Claudeforce runs Claude inside Salesforce's trust boundary, Claude Tag lives inside Slack and Copilot lives inside Microsoft 365.

Workday, which says AI now drives more than a quarter of its new annual contract value, runs its agents inside Workday. An agent that runs inside Salesforce, fires from a Flow, reads CRM records and writes case comments sends nothing past an inspection point, and the same is true of a Copilot agent assembling a document from SharePoint or a Slack-native agent reading years of channel history. The OWASP Agentic Skills Top 10 describes this gap as the "unreachable skill" scenario under AST09, No Governance: a capability deployed inside a third-party platform where no external scanner can go.
