Pinning GitHub Actions to an exact version of their code, known as SHA pinning, has become the go-to defense against software supply chain attacks. In March 2026, the hackers who hijacked Trivy, a widely used open-source security scanner, planted malicious code that looked like it came from GitHub's official checkout tool. That gap is the focus of an upcoming webinar, GitHub Actions Security Beyond SHA Pinning.

GitHub now lets administrators enforce pinning as an organization-wide policy, and few security teams argue against it. 📅 Save Your Spot: Learn Why "Best Practice" Won't Stop the Next GitHub Actions Attack But a pinned SHA leaves three questions unanswered: With agentic development pushing more code through CI than ever, each of those gaps gets exercised more often and reviewed less closely. GitHub's 2026 Actions security roadmap, published March 26, put deterministic dependency locking front and center.
