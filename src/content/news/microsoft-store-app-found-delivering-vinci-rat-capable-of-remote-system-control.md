Cybersecurity researchers have disclosed details of a cyber attack in which a threat actor leveraged a Microsoft Store application to deliver a remote access trojan (RAT) called Vinci RAT. "This access was used to launch a malicious PowerShell stager, establish persistence through a scheduled task, and retrieve a previously undocumented PowerShell-based RAT." Once installed, Setup Assistant acts as a backdoor and is designed to run obfuscated JavaScript that allows it to contact the C2 server at "setup-assistant[.]com" and retrieve arbitrary PowerShell or JavaScript code, ultimately resulting in the deployment of the RAT by means of a stager. Interestingly, the arbitrary PowerShell or JavaScript execution is triggered by means of two methods - The Vinci RAT stager is responsible for running a PowerShell command that disables the Windows Antimalware Scan Interface (AMSI), generates a unique victim identifier, establishes communication with a C2 server ("monkeysholder[.]info/api.php"), set up persistence via a scheduled task that runs every 10 minutes, and downloads the RAT payload.
