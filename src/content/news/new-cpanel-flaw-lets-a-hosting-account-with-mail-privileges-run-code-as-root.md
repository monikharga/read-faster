cPanel has patched a flaw that it says lets a single hosting account take control of an entire server. cPanel published the advisory on September 8 and says every supported version of cPanel and WHM is affected. cPanel's advisory calls it an SQL injection issue in EmailTrack, but does not say which cPanel feature or privilege an account needs.

cPanel is web hosting control panel software. A customer manages one hosting account via cPanel, while the provider manages the entire machine via WHM as the root user. cPanel gave a step like that in its July 30 advisory for a database flaw, where administrators who could not upgrade were told they could temporarily remove the MySQL feature from cPanel users.
