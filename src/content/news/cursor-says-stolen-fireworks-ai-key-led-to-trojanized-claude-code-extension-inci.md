The compromise of Anthropic's official Claude Code extension on Cursor's extension marketplace was the result of the theft of an access key that was exposed in the wake of a breach targeting Fireworks AI. "The key was exposed by Fireworks, and the attacker used it to copy data from a read-only storage bucket we used to share data with them." The disclosure comes nearly two weeks after a trojanized version of Anthropic's official Claude Code extension was distributed through Cursor Marketplace as a legitimate update, attempting to install a persistent SSH backdoor on affected systems. The attacker, Cursor added, used these credentials as a starting point to reach select software-as-a-service (SaaS) tools used by Cursor and then access the following data - Cursor said it took steps to deactivate the vendor's key, revoke and rotate credentials, and hunt for signs of deeper access, and contain it after "we identified further access." The company also said it temporarily disabled internal and product services, disrupting access to some Cursor features.
